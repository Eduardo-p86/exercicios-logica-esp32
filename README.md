# Exercícios de Lógica de Programação com ESP32

Repositório dedicado à prática de lógica de programação com ESP32, Arduino e C++.

## Objetivos

- Praticar lógica de programação.
- Trabalhar com LEDs, botões e display LCD.
- Utilizar `millis()` para controlar o tempo sem bloquear o programa.
- Desenvolver classes e praticar Programação Orientada a Objetos (POO).
- Aprender a organizar código e usar Git e GitHub.
